# Files-App
Files-App 是一個簡單、輕量的 Web 應用程式，用來在瀏覽器中瀏覽與管理伺服器上的檔案。  它專注於最基本、最常用的檔案操作功能，不追求複雜的協作或平台化設計，適合個人、內部系統或小型團隊使用。  主要功能  瀏覽資料夾與檔案結構  上傳、下載、重新命名、刪除檔案  建立與管理資料夾  預覽常見檔案類型  可搭配反向代理進行存取控制  設計理念  簡單優先：只做檔案管理需要的核心功能  輕量部署：容易安裝、容易維護  工具導向：作為系統的一部分，而不是一個平台  Files-App 不試圖取代雲端硬碟或完整協作系統，而是提供一個乾淨、直覺的介面，讓你能快速、安全地存取伺服器上的檔案。
