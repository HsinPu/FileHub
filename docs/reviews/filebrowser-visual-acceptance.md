## 比較條件

來源固定 File Browser `833d908884d5c801f30f5c098d7977177eb3a36b`，65 張來源原圖與實測尺寸依[全畫面研究](filebrowser-visual-reference.md)。FileHub 使用合成帳號、66 項目錄及長中文／圖片／文字／PDF／空目錄；1440×1000、800×1024、390×844、light、scale 1，另驗 1920×1080、斷點與短視窗。字體為本機 Roboto／Material Icons 與明確中文 fallback。

研究中的「FileHub 現況」指 0.39.1，保留當時差距，不回寫成目前版本。改前原圖依 P7.9（本機 `../validation/P7.9.md`）與各份 P8 驗證的 before 圖；最終原圖由本次完整測試取得，不修圖或以 CSS 值替代整頁檢視。秘密只在擷取時遮蔽，真實 8088 使用者畫面不放 Git。

FileHub 特有的服務狀態頁沿用相同殼層、字體、卡片與動作色彩。上游深色登入／圖庫已檢視，但本輪只還原既有淺色頁面；沒有未接契約的主題開關，不宣稱深色已實作。

固定英文來源圖與 FileHub 繁中圖的圖磚／圖庫分組標題使用不同字形行盒，首張卡片頂緣約有 4px 差距；保留中文 fallback 的正常行高，卡片本身的 80／208px 高度與圖示比例不變。資料夾數量不同造成後續分組所在列數不同，不當作版面偏移，也不為模仿參考資料而減少驗收項目。

## 最後收斂

P8.9 將各處 Ant Design 預設空插圖改為共用 Material 空狀態，空目錄的列表不保留沒有資料的表頭；原訊息與錯誤保持。提示字使用次要文字色，停用表單動作保持真正 disabled 並採平面外觀；短對話框的確認動作依 _buttons.css 移除細框線。工作更新期間只顯示實際 loading 圖示，避免窄按鈕同時擠入兩個圖示。

從三視窗原圖確認的工具列殘留已修正：窄版選完檔案或開啟新建對話框會收合更多區，焦點返回可見的更多觸發鈕；不更動控制器或寫入契約。測試另驗上傳要求未重送、新建 Modal 的 Escape 返回焦點；截圖等 Modal 進場完成。工作內容畫面採視窗擷取；管理長頁保留 fullPage 時，收合浮卡仍位於原視窗底部，不能用整張長圖底緣判讀固定位置。
