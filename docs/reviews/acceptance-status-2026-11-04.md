## 2. 目前未提供的功能與既定縮限

以下屬於首版未提供或已明確縮限的能力。若是你的必備需求，須另納主計畫；不應在正式簽收時當成已具備。

| 編號 | 尚未提供／限制 | 目前可用行為與影響 | 依據 |
| --- | --- | --- | --- |
| F01 | 可展開的遞迴目錄樹 | 使用入口、麵包屑與目前目錄瀏覽；目錄樹明確延後 | [P1-workspace](../decisions/P1-workspace.md) |
| F02 | 永久刪除、清空垃圾桶、自動清理政策 | 垃圾桶提供還原，內容保留並持續占用容量；需要容量回收流程時須先補此項 | [P2-trash](../decisions/P2-trash.md) |
| F03 | 舊 Python FileHub 資料庫匯入 | 沒有帳號／權限／設定／分享等舊 DB 轉換工具；未知 DB 會被拒絕 | [發行與相容範圍](../operations/release.md) |
| F04 | 檔案內容全文搜尋 | 已有名稱篩選及有界遞迴名稱搜尋，沒有內容索引 | P6 矩陣（本機 `../validation/P6-matrix.md`） |
| F05 | ZIP 壓縮、加密、解壓及 ZIP64 | 已有 ZIP32 STORE 打包下載；STORE 不壓縮內容，沒有解壓功能 | [P5-archives](../decisions/P5-archives.md) |
| F06 | 影音播放器、內容編輯、完整 PDF 閱讀 | 可安全預覽 PNG／JPEG／WebP、受限 UTF-8 純文字及 PDF 第一頁；其他／超限內容下載原檔 | [P4-previews](../decisions/P4-previews.md) |
| F07 | 每種寫入動作的獨立權限 | 現有 scope 分 browse／download／write；未分開「可新增但不可刪除」等 create／delete ACL | P6 矩陣（本機 `../validation/P6-matrix.md`） |
| F08 | session 自動續期、跨頁累積選取 | session 固定 12 小時、到期重登；切頁清除選取，批次作用於目前選取集合 | [P1 身份](../decisions/P1-session-and-access.md)、P6 矩陣（本機 `../validation/P6-matrix.md`） |
| F09 | TUS 相容協定、任意工作自動重播 | 上傳已有自訂 session v1 的續傳／取消；背景工作只可明確重試可證明未開始的工作，不自動重播不明副作用 | [P3 協定](../decisions/P3-upload-protocol.md)、[P5 工作](../decisions/P5-operations.md) |
| F10 | 持久磁碟縮圖快取、多副本及其他正式平台 | 縮圖採每 API 32 項／16 MiB 記憶體 LRU；第一版只有 Linux／amd64、API／worker 各一，Windows 為唯讀開發平台 | [架構](../../ARCHITECTURE.md)、P6 矩陣（本機 `../validation/P6-matrix.md`） |

實際資料量也須先確認是否符合目前上限：

| 項目 | 目前定案上限／行為 |
| --- | --- |
| 上傳 | 單檔 1 GiB、段 4 MiB、自訂 session 固定 24 小時；不是任意大檔上傳 |
| 複製／搬移／ZIP | 每工作最多 16 根來源、1,000 節點／16 層、合計 2 GiB，單檔 1 GiB；ZIP 產物另有 2 GiB＋8 MiB 上限 |
| 遞迴名稱搜尋 | 深度 8、掃描 10,000、結果 100；到上限明示 partial，不能當整個 NAS 的完整搜尋 |
| 垃圾桶 | 每入口最多 1,000 筆回收歷史；目前沒有永久清空／自動 GC，需先確認長期容量與維護需求 |

限制依 [P3](../decisions/P3-upload-protocol.md)、[P5](../decisions/P5-operations.md)、[P2 垃圾桶](../decisions/P2-trash.md)及 [AGENTS.md](../../AGENTS.md)；若需要上傳／背景複製超過 1 GiB 的單檔，或背景工作超過上述範圍，應在正式搬入前調整契約並驗證。
