## 目前哪些地方有落實

[theme/index.ts](../../apps/web/src/theme/index.ts)與 [Providers.tsx](../../apps/web/src/app/Providers.tsx)已集中主題、字級、常用控制項高度與 CSS 變數；細邊框、淺色表面及焦點樣式也已存在。主要落差在資訊架構、空間分配及操作層級，不能只靠換色或再縮字級解決。

舊 CSS 的綠色 accent 屬歷史實作；本輪不據此替換目前已確認的藍色主題。P1.4 也明確記錄使用原生 select，不能把它說成漏接 Ant Design；若要統一控制項，需連同 DESIGN 的既有決策一起修訂。

## 後續應如何切入

先處理檔案工作空間的殼層寬度、路徑與工具列、主操作及情境選取列；沿用目前資料契約、URL 狀態、controller 生命週期與後端權限。目錄篩選與遞迴搜尋仍保持不同查詢語意，不能為了合併外觀改變範圍。

再整理功能導覽／帳號選單，最後另行處理設定頁的承載方式。目錄樹是 P1.4 明確延後的能力，不在視覺重整時暗中加入遞迴掃描。既有 Modal 的焦點、草稿、送出鎖定及關閉規則應保留。

後續已列入[主計畫 P7](../../IMPLEMENTATION_PLAN.md#p7-整體介面與工作空間收斂)，最新進度只看該主計畫；本報告只保存問題依據，不另維護進度。驗收除功能回歸外，還需相同 1440／800／390px 視窗的前後畫面，覆蓋未選取／已選取、空目錄、長名稱、唯讀／可寫、工作進行中及設定草稿；主計畫另列首屏門檻、1920px 專項及使用者分頁交付要求。
