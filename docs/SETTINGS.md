# 設定與帳號操作調整

## 已確認的操作方式

- 帳號選單固定在左側欄底部，提供「設定與管理」及「登出」。移除右上角與主導覽的重複入口。
- 進入設定時，原本側欄切換成設定導覽；右側呈現內容，全程只有兩欄。
- 設定分為帳號資料、密碼與登入、帳號管理（管理員限定）。
- 返回工作台回到本次進入前的檔案、分享或回收筒位置；直接開啟設定或重新載入後沒有工作台紀錄時，回到所有檔案。
- 工作台內切換保留資料夾、搜尋、排序、清單／縮圖、頁碼與捲動位置；選取會清除，避免套用失效項目。

## 路由與資料

| 網址 | 用途 |
| --- | --- |
| `/settings/profile` | 顯示帳號、顯示名稱及角色；由管理員維護 |
| `/settings/security` | 驗證目前密碼後更新密碼，撤銷所有登入 |
| `/settings/accounts` | 管理員管理帳號、存取範圍及權限 |
| `/admin` | 相容既有書籤，轉到 `/settings/accounts` |

沿用原本密碼 API 與帳號權限檢查，沒有新增資料庫欄位或更改既有帳號。帳號列表新增 `q` 查詢參數，在分頁前搜尋帳號／顯示名稱；百分比及底線當成一般字元搜尋。

一般使用者開啟管理網址會看到無權限提示；API 仍由管理員依賴檢查拒絕。個人設定不提供目前不存在的裝置清單或自行調整權限。

## 操作細節

- 帳號名稱可開啟編輯抽屜；手機使用全寬抽屜。
- 右側抽屜統一預設 800 px，拖曳左側邊緣可調整（最小 480 px、最大視窗寬度減 48 px）；方向鍵微調，雙擊或 Home 還原預設，手機全寬且不顯示拖曳控制。調整時保留表單內容，同一面板關閉再開啟保留本次寬度。
- 新增與編輯表單分基本資料、可存取範圍、操作權限。
- 未儲存時切換分類、返回、瀏覽器上一頁或登出會提示；重新整理使用瀏覽器原生離開提示。
- 密碼值不持久儲存；離開設定後清空。錯誤保留輸入，儲存期間禁止重複操作。
- 上傳與檔案作業由持續掛載的工作台持有，設定切換不會中斷。
- 手機側欄收合，內容頁提供返回按鈕。
