# 第四階段：帳號、權限與分享

## 升級與帳號

資料庫版本 5 新增 account_access 與 audit_events，版本 6 新增 file_shares。版本 5 只在首次遷移時將既有帳號設為啟用的管理員，保留原 users、密碼雜湊與登入連線；後續啟動不會重設權限。缺少 account_access 的帳號拒絕登入，不自動提升角色。

CLI bootstrap 建立第一位管理員。管理員從頁首「帳號管理」新增、編輯、停用帳號，重設密碼或撤銷登入。新增帳號預設停用；一般使用者啟用前須指定現有根目錄及瀏覽權限。帳號名稱不可改、沒有永久刪除。最後一位啟用管理員不能被降級或停用。

新帳號及重設密碼後須先修改密碼；其餘 API 暫時禁止使用。新密碼不能與目前密碼相同。帳號設定更新與重設密碼會撤銷登入，增加權限版本；舊任務／分享會失效。顯示名稱等設定的更新也採此保守規則。

## 存取範圍

每個一般帳號指定一個現有目錄，介面/API 路徑皆相對於自己的根目錄。空字串表示完整檔案空間，null 表示尚未指定。管理員擁有完整存取權。帳號目錄可以重疊，並非每帳號自動建立一份實體檔案空間。

| 權限 | 操作 |
| --- | --- |
| browse | 清單、目錄樹、目前目錄搜尋、自己的垃圾桶 |
| read | 文字、圖片、PDF、縮圖、下載、ZIP |
| upload | 單檔／資料夾上傳、建目錄、還原 |
| modify | 重新命名、搬移 |
| delete | 移至垃圾桶 |
| share | 建立分享；同時需要 read |

複製需要 read＋upload。第一版不提供逐檔權限、群組或禁止下載但允許預覽。所有操作受同一根目錄限制，不能搬移、刪除或重新命名自己的根目錄。

後端 ScopedFiles 逐次解析路徑並重查權限；不追蹤符號連結／junction，沿用保留目錄保護。上傳完成發布前再次驗證。資料夾上傳映射含根目錄及權限版本，舊批次不能在換根後重用。

## 背景任務、ZIP 與垃圾桶

任務保存建立時的權限版本與範圍，提交及背景取消檢查點重新驗證。撤權後不發布尚未完成的複製／ZIP；已完成項目保留。權限版本不符的舊任務不列給一般使用者，不能重新取得 ZIP。下載前再次檢查 read 權限。

ZIP 內檔名相對於該帳號根目錄，避免暴露外層目錄名稱。一般帳號只看自己移入、仍在目前根目錄內的垃圾桶項目；管理員可查看全部。還原重新檢查擁有者與來源範圍，不能透過垃圾桶 ID 越界。垃圾桶以不可修改的帳號名稱記錄擁有者。

檔案系統操作與撤權存在安全檢查點；已開始的短操作或下載串流不承諾即刻中止，也無法收回已取得的位元組。部署仍限單一 worker／容器，假設本機檔案系統由可信任者管理。

## 單檔分享

從檔案「•••」或右鍵選擇分享，期限為 1 小時、1 天或 7 天，預設 1 天；可設定 8–128 字元密碼。僅提供單檔下載，不提供公開目錄、上傳或編輯。

建立後連結只顯示一次，請複製保存。`/share#隨機代碼` 的片段不傳入一般頁面請求，接收頁以 POST body 驗證；資料庫只保存代碼 SHA-256 摘要，密碼使用 Argon2。不得在反向代理或監控中記錄完整請求 body。

公開驗證依 IP 每五分鐘最多 10 次（獨立於帳號登入節流）。驗證成功簽發五分鐘的 HttpOnly、SameSite=Strict、限定下載路徑 Cookie，使用 JWT 獨立 audience。每次下載仍重新檢查分享期限、撤銷、建立者狀態、權限版本、範圍及檔案身分。停留超過五分鐘需重新開啟連結驗證。

重新命名、搬移、刪除、替換或修改來源檔案會使分享失效，需要重建。以裝置／inode、大小、修改時間驗證身分，不提供對抗本機惡意程序偽造檔案資訊的保證。

「分享管理」顯示自己的分享；管理員查看全部並可撤銷。列表的到期／撤銷狀態直接顯示紀錄，來源是否仍有效以開啟／下載時檢查為準。完整連結不再次回傳。

目前 Docker 仍只發布 `127.0.0.1:9005`，本機連結不能供其他電腦使用。對外分享須另外設定網域、HTTPS、Secure Cookie 與可信任反向代理，本階段沒有自動公開網路服務。

## 驗證

- 舊資料庫遷移一次、保留密碼、重新啟動不提升一般帳號。
- 最後管理員保護、強制改密碼、停用及未設定帳號拒絕登入。
- 目錄列表、內容、圖片、PDF、下載、建目錄、上傳、改名與任務的直接 API 權限。
- ZIP 檔名不洩漏父目錄；換根後舊 ZIP 不可下載。
- 他人垃圾桶不可見／不可還原；複製途中撤權不發布並清理暫存。
- 分享密碼、摘要儲存、下載授權、撤銷、到期、來源替換、權限變更及節流。
- 瀏覽器實際新增受限帳號、首次改密碼、唯讀操作、停用後登出、無帳號分享下載與撤銷。
- Docker 容器重建後帳號權限、分享驗證、任務、ZIP、垃圾桶、金鑰與原檔保留。

更新服務前備份 database、config、files，以及升級前程式。需要回復時保留新資料，使用升級前程式及一致的資料庫／檔案備份，不直接覆蓋升級後新增資料。
