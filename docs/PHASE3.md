# 第三階段：資料夾傳輸、ZIP 與媒體預覽

依序完成 3A → 3B → 3C，沿用 React／Ant Design、FastAPI、SQLite 與單一 Docker 容器。

## 3A 資料夾上傳

「上傳資料夾」使用瀏覽器目錄選取器；拖入目錄則遞迴讀取所有分頁，包含空目錄。選取器只提供檔案，因此無法保留純空目錄。

先顯示數量、總容量及同名策略。後端驗證整份清單，再建立目錄並回傳映射；前端最多同時上傳兩檔，逐檔顯示進度、取消與失敗重試。既有同名根目錄整個略過，或建立編號副本，不合併及覆寫既有內容。

限制：最多 1,000 個明列項目、2,000 個含隱含父目錄的節點、32 層、每檔 512 MB、單批 5 GB。拒絕重複路徑、大小寫歧義、檔案／目錄衝突及保留名稱。

相同 request_id 重送取得相同映射；目錄建立中斷的批次回應 409，需要確認現況後重新選取。已建立目錄與已完成檔案保留，取消不會回滾整批。瀏覽器重新整理後不保留本機 File 物件，需重新選取。

## 3B ZIP 打包下載

選取項目後按「打包下載 ZIP」，或由右鍵選單開始。整理任務顯示等待、執行、取消或完成；完成後由任務下載。ZIP 內保留工作空間相對路徑與空目錄。

來源最多 100 個選取項目、展開後 10,000 項／1 GiB；輸出最多 1,100 MiB。暫存總額 2 GiB，並檢查可用磁碟空間。逐塊讀寫，不將整包載入記憶體；來源變更會失敗，不發布半成品。

ZIP 存在資料庫旁 `archives/`，完成一小時後禁止下載；背景工作者閒置時每分鐘及啟動時清理。開啟中的 Windows 下載可能延後實體刪除。取消或失敗清理暫存，來源不變。重啟中斷任務標記待檢查，不自動重跑。下載僅供任務擁有者。

## 3C 縮圖與預覽

清單／縮圖可切換。縮圖每頁 24 項，原圖延遲載入；核取方塊多選、圖片按鈕開啟、右鍵與更多操作沿用既有功能。這版尚未產生伺服器端縮小圖片，因此大圖的下載成本仍依原始檔大小。

圖片預覽可依目前搜尋結果前後切換。切換時中止舊請求並拒絕遲到結果。圖片端點需登入，限制 10 MB，SVG 回應具 sandbox CSP。

PDF 使用 PDF.js 獨立載入模組／worker，字型與字元映射隨建置封裝，不連外載入。限制 50 MB、200 頁，一次繪製一頁、canvas 最多約 800 萬像素；切換或關閉會取消工作。支援翻頁及下載原檔，不執行 PDF 指令碼；WASM 解碼停用，特殊影像或損壞文件可能無法預覽。Canvas 頁面提供頁碼標籤，本版尚無可選取文字層。
