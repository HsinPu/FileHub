# 公開分享操作

公開頁使用獨立頂列與閱讀區，不顯示私有側欄；單檔以「下載原檔」取得內容，資料夾提供範圍內的導覽與逐檔下載。右上「登入 FileHub」前往私有登入；公開分享本身不會授予帳號權限。

1. 在檔案列表選取一個有下載權限的檔案或資料夾，按「分享所選項目」。
2. 選擇 1／7／30 天，可設定 15–128 字元密碼；按「建立分享」。
3. 保存完整連結並另行告知密碼。完整連結只在當次對話框顯示；關閉後不能再次取回。
4. 連結持有人開啟獨立公開頁，輸入密碼或按「開啟分享」，只能瀏覽分享範圍及下載原檔。
5. 到側欄「分享管理」頁（`/?view=shares`）可撤銷自己的分享。頁面可刷新與返回，保留檔案入口／路徑等 query 上下文；撤銷中會阻擋離開並顯示等待原因。來源移動、刪除、同名替換、owner／入口停用或下載權限撤回也會停止提供內容。

建立失敗或回應遺失時先按「查詢建立結果」，不要另開對話框重複建立。公開頁密碼錯誤或連線失敗可重試；嘗試次數過多須等待節流期間。過期或缺少完整 fragment 的連結需由分享者重新提供。公開頁 Cookie 不會授予 FileHub 帳號權限。

分享資料夾不代表檔案快照；原地編輯同一物件會反映新內容。只會下載原檔，不執行 HTML／SVG。反向代理應提供同源 HTTPS，設定正確 `FILEHUB_PUBLIC_ORIGIN`；不要把 Authorization、Cookie 或請求內容寫入代理日誌。更多邊界見[分享決策](../decisions/P6-sharing.md)。
