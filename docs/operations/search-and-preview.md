# 搜尋、預覽與縮圖

> 驗證報告與原始擷取保留本機，未隨原始碼發佈；文中「本機」路徑僅作歷史定位，不能視為新 checkout 已有的證據。

先登入並選擇可存取的入口／相對目錄。按頂列「搜尋檔案」展開全頁搜尋；「返回檔案」或 Escape 取消未送文字／遞迴結果並收合，保留原 URL 的目錄篩選。要移除已套用篩選，按「清除搜尋」。

1. **目前資料夾**：在同一個名稱輸入選此範圍，輸入片段後按「搜尋」，只篩選這一層，包含尚未顯示的分頁；URL 保留篩選，切換目錄會清除。最多處理 5,000 個項目，超過時請縮小目錄。
2. **包含子目錄**：選此範圍後按「搜尋」，結果另列完整相對路徑。不區分大小寫、不搜尋內容；可送出新查詢或按「清除搜尋」取消。最多 8 層、10,000 次掃描、100 筆結果及 2 秒檢查點期限；完整限制可按「搜尋說明」。出現「部分結果」表示尚未涵蓋全部內容，請縮小目錄或調整名稱；外部掛載的 I/O 等待可能延長實際耗時。
3. **預覽**：列表檔名／預覽、縮圖或搜尋結果可開啟全畫面安全預覽；頂列提供關閉、重試、原檔下載與「預覽資訊」。長相對路徑可在資訊內鍵盤捲動。文字以純文字呈現，圖片經轉碼，PDF 只顯示第一頁。按 Escape 或「關閉預覽」返回；不支援／損壞／超限時可重試或下載原檔。檔案版本已變更時，關閉後重新整理列表再開啟。
4. **三種檢視**：內容區檔案工具列的「切換檢視」依序切換列表／圖磚／圖庫，圖示與文字表示目前模式，提示顯示下一種模式；選取後的工具列也能切換。路徑與目前 snapshot 的選取會保留。圖片接近可視範圍才載入，失敗可重試；其他格式／資料夾顯示類型圖示。

從「選取項目」、Space、Ctrl／Command 點擊、右鍵或資源的「更多操作」開始；原單擊仍開啟資料夾或安全預覽。選取後才顯示分享、下載、複製／剪下及 ZIP；重新命名、移至垃圾桶、重新整理與排序在「更多所選操作」。手機檔案列保留預覽，下載位於該列「更多操作」；完整名稱仍可由可存取標籤辨識。沒有下載／寫入等能力時，相關動作維持停用。

瀏覽名稱的權限不等於取得內容。原檔下載、預覽與縮圖都需要目前 download grant；撤權、停用帳號／入口或來源消失後不能從 cache 取回內容。不能開啟 symlink 或 `.filehub` 私有內容。

預覽限制：PNG／JPEG／WebP 8-bit 單張 16 MiB／16 MP、非動畫；UTF-8 文字 256 KiB；PDF 16 MiB。需要完整 PDF、特殊字型、動畫或其他格式時下載原檔。文字中的 HTML／SVG／Markdown／程式碼不執行，也不轉為可互動 HTML。

API 使用 32 項／16 MiB 記憶體 LRU，重啟後自動按需重建；預留 cache volume 此版不寫入。沒有背景預生成或需要恢復的轉檔工作。故障排查與測試邊界見[預覽政策](../decisions/P4-previews.md)、[縮圖決策](../decisions/P4-thumbnails.md)及P4.4 驗證（本機 `../validation/P4.4.md`）。
